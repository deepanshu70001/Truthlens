## Implementation and pipeline contract

- Reworked `backend/app/services/nlp/language_detector.py` with cache-only loading, one-time initialization, synchronized model reuse/inference, safe load/inference errors, mapping validation, 4,096-character input bounding, tokenizer max length 256, and explicit truncation metadata.
- Empty OCR text returns `completed/no_text`; malformed, too-short, or mostly non-letter OCR input returns `completed/insufficient_input`; model or dependency absence returns `unavailable/unavailable`; execution or malformed-output errors return `failed/failed`. A maximum softmax score below 0.70 or an unknown label returns `completed/undetermined`. The reported score is the model's maximum softmax probability, range 0–1, and is explicitly not calibrated.
- The result keeps compatibility fields (`detected_language`, `top_languages`, `model_name`, `runtime_ms`, and `warnings`) and adds nullable language name/code, model version/revision, input/truncation metadata, confidence semantics, and limitations. The original OCR string is passed unchanged to the language service.
- Added an optional `language_identification` stage after OCR, vision, and XAI, before text normalization. It uses the E1 `StageResult` path, stable stage/correlation IDs, normal timestamps/runtime/output reference, and a configurable 30-second wait. Missing model weights do not block the preceding image-analysis stages. As with Python thread timeouts, a timed-out model call cannot be forcibly stopped and may continue in the worker thread.
- The result is exposed as `report.language_identification`; older reports without this optional field remain readable. The frontend uses optional access and displays the result when present, and its progress list includes the new stage.
- Only a confident supported language code is passed to the existing claim language metadata argument; otherwise claims receive `unknown`. The claim extraction algorithm is unchanged. The existing OCR script estimate remains separate and continues to serve legacy fact-check/regional/social inputs. Language output does not enter evidence or fusion and does not affect authenticity scoring.
