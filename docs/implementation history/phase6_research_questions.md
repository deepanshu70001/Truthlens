# Phase 6 research questions and operationalization

The questions below are preregisterable targets. Because the repository lacks approved labeled corpora, the empirical questions are currently **open**; no null result or performance claim is inferred.

| RQ | Objective / hypothesis | Independent variables | Dependent variables | Dataset and method | Limitation / current status |
|---|---|---|---|---|---|
| RQ1 Authenticity | Measure whether the configured SigLIP2 detector distinguishes genuinely sourced photographs from fully generated images. H1: performance exceeds a majority-class baseline on a source/event-grouped held-out set. | Ground-truth class, generator family, source event, compression/transform, fixed threshold | Sensitivity, specificity, precision, recall, F1, ROC-AUC, PR-AUC, abstention coverage | Public dataset only after rights review; source/event/generator grouped train/validation/test; fixed pretrained model; majority baseline; report class counts and CIs | No eligible manifest; not answered. Edited/inpainted images require separate task labels. |
| RQ2 Explainability | Test whether Grad-CAM is target-class-consistent, stable under small transformations, and useful to reviewers. | Target class, image transform, model parameter randomization, reviewer/task condition | Artifact integrity, rank/overlap stability, deletion/insertion change, localization metric with masks, reviewer ratings | Same labeled images plus region masks and consented reviewers; sanity checks before user study | No masks/participants; attractive overlay is not faithfulness evidence. |
| RQ3 Forensics | Determine whether classical indicators add complementary discriminatory information to the detector. | Authenticity-only vs authenticity+forensics; per-signal inclusion | Paired metric difference, coverage, errors by transform and file encoding | Same independent labeled images with edited/authentic provenance; paired ablation | No labels; forensic cues may be correlated and non-directional in the current pipeline. |
| RQ4 Text/fact checks | Measure claim-span extraction and provider evidence retrieval separately from verdict attribution. | Claim type, OCR quality, query language, provider availability | Span precision/recall/F1; Precision@K, MRR; human-rated match/verdict agreement; unavailable rate | Human-reviewed claims with source evidence and date, separate provider logs | No annotated set, no credentials in run; retrieval failure is not verdict error. |
| RQ5 Multilingual | Measure OCR and claim extraction only for explicitly supported languages. | Language/script, resolution, rotation, font, compression, mixed-script condition | CER/WER, language/script confusion, span metrics, per-language failure rate | Licensed multilingual image-text benchmark plus reviewed Hinglish examples | Current configured OCR en/hi; language output is script estimate; no translation component. |
| RQ6 Social analytics | Establish which outputs are observational versus heuristic and whether any output predicts outcomes. | Feature toggles, input text/cues, region/reference table version | Heuristic determinism/consistency; if outcome data later exists: time-bounded ranking/regression metrics | Current code review and controlled scenarios; prospective permitted spread outcomes for predictive claims | Currently no virality/regional/impact outcome data; all predictions open/not evaluable. |
| RQ7 Integrated system | Characterize completion, partial failure, latency, resource use, evidence traceability and report rendering. | Image size/format, optional dependency availability, failure injection, hardware | success/partial/failure rates, per-stage/total latency, CPU/RAM/GPU, traceability and UI assertions | Repeatable generated synthetic fixtures for reliability/performance; no inference on truth | Existing API test suite passes; one uncontrolled browser run is not a performance sample or usability study. |

For all confirmatory tests, freeze the model and protocol before opening the held-out test split. If sample size is too small for meaningful intervals or subgroup comparisons, report counts and descriptive metrics only.
