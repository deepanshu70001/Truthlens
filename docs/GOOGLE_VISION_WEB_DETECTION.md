## 1. Executive Summary

This document details the architecture, request structure, defensive normalization, error handling, and empirical status of the Google Cloud Vision Web Detection integration in TruthLens.

The Web Detection feature is designed to perform reverse-image search and detect occurrences of an uploaded image across the public web. It extracts matching web pages, exact matching images, partially matching images, visually similar images, best-guess textual labels, and associated web entities.

In accordance with strict verification rules, this integration is classified as **IMPLEMENTED BUT CREDENTIAL BLOCKED** because the local application implementation is complete and verified against mock test suites (7/7 passed), but the user's configured Google Cloud project currently returns HTTP 403 `PERMISSION_DENIED` on live API calls.

## 2. API Architecture & Request Protocol

### 2.1 Configuration Keys

The service queries configuration settings in the following order of precedence:

| Environment Variable | Role | Priority |
| :--- | :--- | :---: |
| `VISION_API_KEY` | Dedicated API key for Cloud Vision API | 1 (Primary) |
| `GOOGLE_API_KEY` | Shared Google Cloud project key | 2 (Fallback) |

```python
# backend/app/config.py
VISION_API_KEY: str = ""
GOOGLE_API_KEY: str = ""
```

### 2.2 Request Specification

The service communicates with the official Cloud Vision Annotate API:
- **URL:** `POST https://vision.googleapis.com/v1/images:annotate?key={api_key}`
- **Headers:** `Content-Type: application/json`
- **Payload Structure:**
```json
{
  "requests": [
    {
      "image": {
        "content": "<base64-encoded image bytes>"
      },
      "features": [
        {
          "type": "WEB_DETECTION",
          "maxResults": 20
        }
      ]
    }
  ]
}
```

### 2.3 Response Parsing & Entity Extraction

The response is parsed into strongly typed models:
- **`web_entities`:** Topical entity descriptions with associated entity IDs and provider confidence scores.
- **`matching_pages`:** Web pages hosting the image, extracting page titles, full URLs, and domain publisher attribution.
- **`matching_images`:** URLs of bit-exact or partially matching image files found online.
- **`similar_images`:** Visually similar images identified by Google's visual index.
- **`best_guess_labels`:** Human-readable descriptive phrases generated by Google Vision.

## 3. Defensive Security Controls

To ensure production safety and protect against external provider exploitation:
1. **URL Sanitization:** Every external URL in `matching_pages` and `similar_images` is validated against a strict scheme whitelist (`https` only, non-empty hostname, valid port). Query strings are parsed and all credential parameters (`key`, `token`, `secret`, `signature`, `password`) and tracking parameters are deleted before storage or transmission to the frontend.
2. **Response Size Bound:** The incoming response stream is capped at a hard limit of 2 MB (`2 * 1024 * 1024` bytes). Responses exceeding this limit are aborted with `PROVIDER_RESPONSE_TOO_LARGE`.
3. **Concurrency Limiter:** Web Detection requests are guarded by an asynchronous semaphore (`_WEB_DETECTION_SEMAPHORE = threading.Semaphore(2)`), preventing thread pool exhaustion during bursts.
4. **Timeout Envelopes:** Requests are bound by `PROVENANCE_API_TIMEOUT_SECONDS` (default 30.0s) and total deadline `PROVENANCE_MAX_TOTAL_SECONDS` (default 35.0s).
